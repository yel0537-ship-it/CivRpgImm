# Прогресс вертикального среза

Срез покрывает три эпохи (Первобытная, Городов-государств, Античных царств); остальные девять эпох заведены в `eras.json`
с `implemented: false` и подключаются данными.

## Как проверялось

- **Game.Core** собирается .NET SDK (C# 9, netstandard2.1) и проходит **47 EditMode-тестов** (`tools/check.sh --core`).
- **Game.Presentation** компилируется против референс-сборок UnityEngine 2021.3 (NuGet `UnityEngine.Modules`) по ветке старого Input Manager.
  Ветку Input System, Editor-скрипты и сам рендер в Unity 6 проверить в этой среде было нельзя: Unity здесь не установлен.
  **Первый запуск в редакторе — главный незакрытый риск**; возможны мелкие правки API.
- Снимки `tools/screenshots` не снимались по той же причине; сценарии для них готовы.

## Доработки второй итерации

- **Слой ассетов** (`Presentation/Assets`): модели, анимации, оружие в руке, эффекты, текстуры, портреты, иконки, звук —
  по соглашению имён или `visuals.json` / `audio.json`, с заглушками по умолчанию. Окно редактора «Immortal → Покрытие ассетов». См. [ASSETS.md](ASSETS.md).
- **Анимации**: мост к Animator со стандартными параметрами, процедурная анимация примитивов (шаг, замах, выпад, удар, смерть, сбор).
- **Звук**: эффекты на все события, шаги, музыка по ситуации с перекрёстным затуханием, фон регионов и дыма, синтезированные заглушки, громкость в «Настройках».
- **Местность**: массив текстур по типам (свои PNG или процедурные), времена года, солнце для моделей.
- **Бой**: особые умения у сильных врагов (удар по области, натиск, прыжок, снаряд), видимые зоны ударов на земле, сектор замаха, тряска камеры, кольцо наведения и маркер клика, полоса сбора.
- **Подсказки**: 13 целей основного пути (`objectives.json`) в трекере HUD; миникарта.
- **Мир живёт**: жители бродят по городам (в голод — меньше и медленнее), погода по регионам, новые события (спор спутников, праздник, мор, бунт потомков обиженного, легенда о возвращении, неподвижная звезда, разбойники на дорогах), память соперника в личной встрече.

## Третья итерация

- «Куклы» из примитивов: туловище, голова, руки и ноги на шарнирах; процедурный шаг, замах, удар, сбор; оружие в кисти.
  Внешность по FaceId — потомок с тем же лицом выглядит как предок. Спутники отмечены синей перевязью.
- Дым как сбой: внутри зоны парят одинаковые кубы правильной сеткой и перескакивают на шаг.
- Журнал (J): цель, просьбы людей, что известно о людях, судьбы спутников, потомки, воспоминания.
- «!» над врагом, который заметил героя; ускорение времени ×5 (T) вне боя; метаданные сохранений (год, роль, глава).
- Быстрые перемещения по дорогам с карты (время в пути проходит); реплики жителей и спутников по состоянию державы.
- Послы влияют на отношения и сделки; свои аванпосты; постройки, меняющие местность (осушение болот, лесоповал).
- Дозоры у знамён границы; масштаб интерфейса; имя героя; дикие враги крепнут с эпохой; у бессмертных правителей боевые умения.
- Bootstrap создаёт стандартную тему UI Toolkit и повторяет настройку один раз на машине.

## Известные упрощения

- Интерьеры — информационная панель вместо отдельной сцены; «войти» = открыть панель услуг.
- Рельеф — гладкие высоты с плоским цветом тайлов; вода — пониженные тайлы без шейдера воды.
- Армии вдали — группа капсул; в бою — до 12 солдат на сторону, остальное — резерв силы.
- Поиск пути армий — тот же A* по тайлам (с лимитом), дороги лишь удешевляют движение.
- UI без темы оформления: всё стилизовано из C#; скроллбары могут быть невидимыми (колесо работает).
- Баланс выставлен тестами и ботом, но не живой игрой — первые часы игры стоит подкрутить через `balance.json`.
