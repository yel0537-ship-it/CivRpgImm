# Прогресс вертикального среза

Срез покрывает три эпохи (Первобытная, Городов-государств, Античных царств); остальные девять эпох заведены в `eras.json`
с `implemented: false` и подключаются данными.

## Как проверялось

- **Game.Core** собирается .NET SDK (C# 9, netstandard2.1) и проходит **47 EditMode-тестов** (`tools/check.sh --core`).
- **Game.Presentation** компилируется против референс-сборок UnityEngine 2021.3 (NuGet `UnityEngine.Modules`) по ветке старого Input Manager.
  Ветку Input System, Editor-скрипты и сам рендер в Unity 6 проверить в этой среде было нельзя: Unity здесь не установлен.
  **Первый запуск в редакторе — главный незакрытый риск**; возможны мелкие правки API.
- Снимки `tools/screenshots` не снимались по той же причине; сценарии для них готовы.

## Известные упрощения

- Интерьеры — информационная панель вместо отдельной сцены; «войти» = открыть панель услуг.
- Рельеф — гладкие высоты с плоским цветом тайлов; вода — пониженные тайлы без шейдера воды.
- Армии вдали — группа капсул; в бою — до 12 солдат на сторону, остальное — резерв силы.
- Поиск пути армий — тот же A* по тайлам (с лимитом), дороги лишь удешевляют движение.
- UI без темы оформления: всё стилизовано из C#; скроллбары могут быть невидимыми (колесо работает).
- Баланс выставлен тестами и ботом, но не живой игрой — первые часы игры стоит подкрутить через `balance.json`.
